# Medical Image Analysis

A Python project exploring AI-assisted medical image analysis with deep learning and agent-based components.

## Overview

The project combines image-processing and machine-learning libraries with an AI agent layer to explore workflows for analyzing medical images and presenting useful output.

## Technology

- Python
- OpenAI Agents SDK
- TensorFlow and Keras
- NumPy
- Pillow
- Flask and Gunicorn
- Hugging Face Hub
- python-dotenv
- Markdown

## Purpose

This project demonstrates how computer vision, deep learning, and AI agents can be combined in an application-oriented medical image analysis workflow.
